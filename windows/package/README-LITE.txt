Codex Dream Skin Windows v0.3.7 - Lite

这是体积更小的运行时依赖版本。

运行前需要安装：

1. Microsoft .NET 10 Desktop Runtime x64
2. Microsoft Windows App SDK Runtime 2.3 x64

Official runtime downloads:
https://dotnet.microsoft.com/download/dotnet/10.0
https://learn.microsoft.com/windows/apps/windows-app-sdk/downloads

安装依赖后，完整解压 ZIP 并双击 CodexDreamSkin.exe。不要只复制 EXE；
DLL、PRI、资源和主题文件必须保留在一起。

系统要求：Windows 10 1809 或更高版本 / Windows 11，x64。
当前版本未进行代码签名，请只从官方 GitHub 仓库下载并核对 SHA-256。

Official repository:
https://github.com/jojhaa/Codex-Dream-Skin-Windows
