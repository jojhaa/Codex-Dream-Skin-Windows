Codex Dream Skin Windows v0.3.6 - Portable

这是免安装运行时的绿色版本。

1. 完整解压 ZIP 到普通文件夹。
2. 不要只复制 CodexDreamSkin.exe；DLL、PRI、资源和主题文件必须保留在一起。
3. 双击 CodexDreamSkin.exe 启动。

系统要求：Windows 10 1809 或更高版本 / Windows 11，x64。
当前版本未进行代码签名，请只从官方 GitHub 仓库下载并核对 SHA-256。
