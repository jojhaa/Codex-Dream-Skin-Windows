## 立即使用

### 1. 下载

**[下载 CodexDreamSkin-Windows-x64-v0.3.5.zip](https://github.com/jojhaa/Codex-Dream-Skin-Windows/releases/download/v0.3.5/CodexDreamSkin-Windows-x64-v0.3.5.zip)**

无需安装 .NET SDK，也不需要克隆仓库。

### 2. 完整解压

将 ZIP 完整解压到普通文件夹，保留其中的 DLL、PRI、运行库、资源和主题文件。不要只复制单个 EXE。

### 3. 运行并应用

双击 `CodexDreamSkin.exe`，在主题管理器中选择或编辑主题，然后点击“正式应用”。

如需普通启动 Codex 后自动套用主题，可在设置中启用实时同步、自动接管和开机自启动。

## 工作方式

```text
Codex Dream Skin 管理器
        │
        ├─ 管理主题图片、配色、材质与构图
        ├─ 通过 127.0.0.1 回环 CDP 应用主题
        └─ 热重载当前 Codex 渲染页面

Codex 官方文件保持不变
```

启动器会动态查找当前 Microsoft Store Codex 包和真实进程路径，因此 Codex 更新后不会依赖旧的固定版本目录。

## 安全边界

| 会做 | 不会做 |
| --- | --- |
| 使用仅绑定 `127.0.0.1` 的本机 CDP 会话 | 修改或重新签名 Codex 安装包 |
| 在接管或关闭前重新验证包和进程身份 | 写入 `WindowsApps` 或解包 `app.asar` |
| 将主题、备份和设置保存在用户目录 | 修改 API Base URL、API Key 或账户数据 |
| 使用管理器进程内的原生 Windows 托盘 | 安装隐藏的 PowerShell 托盘快捷方式 |
| 提供明确的恢复和诊断入口 | 将调试端口暴露到局域网 |

启用 CDP 期间，请不要运行不受信任的本地程序。

## 源码与开发

普通用户只需要使用上面的绿色包。以下内容面向开发者和需要脚本工作流的用户。

### 从源码运行管理器

需要安装 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)。

```powershell
git clone https://github.com/jojhaa/Codex-Dream-Skin-Windows.git
cd Codex-Dream-Skin-Windows\windows
dotnet run --project .\app\CodexDreamSkin\CodexDreamSkin.csproj -c Release -p:Platform=x64
```

### 自行构建 x64 绿色版

```powershell
cd Codex-Dream-Skin-Windows\windows
dotnet publish .\app\CodexDreamSkin\CodexDreamSkin.csproj `
  -c Release `
  -p:Platform=x64 `
  -r win-x64 `
  -p:PortableExe=true `
  -o ..\release\CodexDreamSkin-win-x64
```

### 脚本工作流

```powershell
# 安装并启动主题引擎
powershell -ExecutionPolicy RemoteSigned -File .\scripts\install-dream-skin.ps1
powershell -ExecutionPolicy RemoteSigned -File .\scripts\start-dream-skin.ps1

# 验证运行环境和当前主题
powershell -ExecutionPolicy RemoteSigned -File .\scripts\verify-dream-skin.ps1

# 恢复 Codex 原始外观
powershell -ExecutionPolicy RemoteSigned -File .\scripts\restore-dream-skin.ps1
```

### 开发验证

```powershell
cd windows
powershell -ExecutionPolicy Bypass -File .\tests\run-tests.ps1
dotnet build .\app\CodexDreamSkin\CodexDreamSkin.csproj -c Release -p:Platform=x64 -nologo
```

## 已知限制

- 主题依赖 Codex 当前的 Electron/Chromium DOM；Codex 大版本更新后可能需要更新选择器。
- “普通启动自动应用”是可选用户级接管功能，关闭后普通 Codex 不会自动带主题。
- 实时界面测试要求本机 Codex 正在运行并已开启受管理的 CDP 会话。
- 本项目是非官方工具，与 OpenAI 无隶属或认可关系。
