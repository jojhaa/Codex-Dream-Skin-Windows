# Codex Dream Skin v0.3.2

`v0.3.2` is the first public release of the `jojhaa` personal edition: a Windows-first visual theme studio for Codex Desktop.

## What is new

- Native WinUI 3 theme manager with library, history, import/export, diagnostics, and settings.
- Six independently configurable artwork regions with real Codex proportions.
- Non-destructive source-image viewport editing with focus, zoom, fit, and offsets.
- Instant light/dark preview, automatic palette extraction, contrast checks, and component-level glass materials.
- Continuous hot reload and optional background takeover for ordinary Codex launches.
- Deep Kanna Blue coverage for Settings, utility pages, terminal/review panels, menus, messages, composers, and both sidebar modes.
- Dynamic discovery of updated Codex Store packages and guarded loopback-port management.

## Install

Clone the repository and use the Windows scripts:

```powershell
git clone https://github.com/jojhaa/Codex-Dream-Skin-Windows.git
cd Codex-Dream-Skin-Windows\windows
powershell -ExecutionPolicy RemoteSigned -File .\scripts\install-dream-skin.ps1
powershell -ExecutionPolicy RemoteSigned -File .\scripts\start-dream-skin.ps1
```

To run the native manager from source, install the .NET 10 SDK:

```powershell
dotnet run --project .\app\CodexDreamSkin\CodexDreamSkin.csproj -c Release -p:Platform=x64
```

## Important

This is an unofficial personal project and is not affiliated with OpenAI. It does not patch Codex binaries or WindowsApps. The theme engine uses a loopback-only CDP session while active; do not run untrusted local software during that session.
