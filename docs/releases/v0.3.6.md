# Codex Dream Skin Windows v0.3.6

## 中文版本日志（主要）

`v0.3.6` 修复最新版 Codex Desktop 页面结构变化造成的主题应用失败，同时继续兼容旧版 Codex 页面。

### 修复内容

- 支持 Codex `26.727.6591.0` 使用的稳定 `data-app-shell-main-surface` 与 `data-app-shell-application-menu-bar` 标记。
- 同步更新主题目标检测、早期注入、实时预览截图、区域测量、渲染路由以及主题 CSS。
- 支持最新版主内容顶部渐隐层和任务内容边界框，不依赖会随构建变化的哈希类名。
- 将样式架构升级至 70，使已经运行的 Codex 页面立即替换旧版 CSS。
- 继续排除 `avatar-overlay` 等辅助 `app://` 页面，避免主题影响悬浮辅助窗口。

### 验证结果

- 完整 Windows 自动化测试通过。
- x64 Release 编译通过，零警告、零错误。
- 在真实 Codex `26.727.6591.0` 上通过“正式应用”验证。
- 主页面存在主题类、样式架构 70 和对应页面路由类。
- 辅助 `avatar-overlay` 页面不存在主题类和主题样式表。
- Portable 与 Lite 发布包均经过全新解压和响应窗口启动验证。

## English Summary

`v0.3.6` restores theme application on current Codex Desktop releases after the main-shell markup changed, while retaining compatibility with older builds.

### Highlights

- Supports the stable `data-app-shell-*` markers in Codex `26.727.6591.0`.
- Updates native and Node probes, early injection, live capture, region measurement, renderer routing, and production CSS.
- Uses stable attributes instead of build-specific hashed class names.
- Bumps the stylesheet schema to 70 for immediate live replacement.
- Keeps auxiliary targets such as `avatar-overlay` isolated and unthemed.
- Includes executable live validation against the current Codex main and auxiliary pages.
