# Codex Dream Skin Windows v0.3.7

## 中文版本日志（主要）

`v0.3.7` 修复最新版 Codex Desktop 中编辑菜单命令仍显示英文的问题。

### 修复内容

- 适配最新版 Codex 独立的 `role="menubar"` 应用菜单结构。
- 通过稳定的 `application-menu-trigger-file-menu`、`application-menu-trigger-edit-menu`、`application-menu-trigger-view-menu` 和 `application-menu-trigger-help-menu` 触发器接管菜单。
- 不再依赖最新版已经移除的 `group/application-menu-top-bar` 标题栏类。
- 继续保留旧版 Codex 菜单结构兼容。
- 样式架构升级至 72，已运行页面会替换旧版菜单监听器。

### 真实 Codex 验证

- 文件菜单：6 个中文命令。
- 编辑菜单：8 个中文命令，包括 `撤销、重做、剪切、复制、粘贴、删除、全选、设置…`。
- 视图菜单：18 个中文命令。
- 帮助菜单：8 个中文命令。
- 四个菜单均未超出当前 Codex 窗口。
- 完整 Windows 自动化测试和 x64 Release 编译通过。
- Portable 与 Lite 发布包均经过全新解压启动验证。

## English Summary

`v0.3.7` restores complete Chinese application-menu translation on current Codex Desktop builds.

### Highlights

- Supports the current standalone Radix-style application menubar.
- Uses narrow, stable `application-menu-trigger-*` identifiers instead of the removed title-bar class.
- Retains the legacy application-header path for older Codex builds.
- Verifies exact translated Edit labels and all menu counts against the real Codex renderer.
- Bumps the style schema to 72 for immediate listener replacement.
