# Codex Dream Skin Windows v0.3.4

## 中文版本日志（主要）

`v0.3.4` 是面向 Windows 版 Codex Desktop 的可视化主题工作室版本。本次更新将主题编辑器、绿色运行环境、诊断工具、自动接管、应用菜单翻译与原生托盘生命周期整合到一个自包含绿色包中。

### 主要更新

- 新增原生 WinUI 3 主题管理器，包含概览、主题、诊断和设置页面。
- 支持主背景、左侧栏、任务输入框、首页照片框、首页输入框和拍立得六个独立图片区域。
- 支持基于 Codex 真实比例的取景、焦点 X/Y、缩放、填充方式和水平/垂直偏移，编辑过程不破坏原始图片。
- 新增浅色/深色即时预览、自动配色、肤色规避、对比度提示和组件级玻璃材质。
- 支持主题热重载，以及普通启动 Codex 后自动应用主题的可选接管模式。
- 新增原生 Windows 托盘：关闭窗口转入后台、双击恢复，右键可打开管理器、主题、诊断、设置，也可隐藏或彻底退出。
- 新增开机自启动，兼容应用包和绿色版。
- 自动发现 Microsoft Store 更新后的 Codex 安装路径，不再绑定某个固定版本目录。
- 新增本机回环端口诊断、占用进程识别和经过身份复核的安全关闭操作。
- 设置页新增版本检测、永久免费与开源声明、退款提醒和唯一官方项目地址。
- 新增文件、编辑、视图、帮助四组 Codex 应用菜单中文翻译，并适配主题明暗材质。
- 更新透明背景应用图标，并同步到 EXE、窗口、托盘、开始菜单、磁贴和启动画面。

### 重要修复

- 修复绿色版进入诊断页或设置页时可能闪退的问题。
- 修复干净发布后内置主题图片路径失效的问题。
- 修复托盘注册失败时窗口仍被隐藏、导致后台进程无法访问的问题。
- 修复托盘菜单、页面导航、普通二次启动、隐藏、恢复和彻底退出之间的生命周期不同步。
- 改进设置页、悬停抽屉、插件、站点、拉取请求、聊天、终端、审查面板、摘要和待发送消息区域的主题覆盖。

### 安全边界

- 不修改 Codex 二进制文件、`WindowsApps` 或 `app.asar`。
- CDP 仅绑定 `127.0.0.1`。
- 接管或关闭进程前会重新验证应用包与进程身份。
- 不安装隐藏的 PowerShell 托盘快捷方式。
- 托盘图标运行在原生管理器进程内部。
- 当前版本暂未签名，代码签名流程已暂缓。
- 绿色包继续保留公开主题人物素材。

## English Summary

`v0.3.4` is a Windows-only release of the visual theme studio for Codex Desktop.

### Highlights

- Native WinUI 3 manager with Overview, Themes, Diagnostics, and Settings.
- Six independent, non-destructive artwork viewports with real Codex proportions.
- Instant light/dark preview, automatic palette extraction, contrast guidance, and component-level glass materials.
- Hot reload and optional automatic takeover after an ordinary Codex launch.
- Native Windows notification-area lifecycle with close-to-background, double-click restore, localized navigation, hide, and full exit commands.
- Packaged and portable Start with Windows support.
- Dynamic Store package discovery, managed loopback-port diagnostics, and guarded verified-process controls.
- Version checks, authenticity information, a free/open-source notice, and refund guidance.
- Chinese File, Edit, View, and Help menus with theme-aware popup materials.
