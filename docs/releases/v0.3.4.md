# Codex Dream Skin Windows v0.3.4

`v0.3.4` is a Windows-only release of the visual theme studio for Codex Desktop. It combines the theme editor, portable runtime, diagnostics, automatic takeover, application-menu translation, and native notification-area lifecycle in one self-contained green package.

## Highlights

- Native WinUI 3 theme manager with Overview, Themes, Diagnostics, and Settings.
- Six independently configurable artwork regions using non-destructive source-image viewports.
- Real Codex-ratio composition, focus, zoom, fill, offsets, and immediate light/dark preview.
- Automatic palette extraction, skin-tone avoidance, contrast guidance, and component-level glass materials.
- Hot reload and optional automatic takeover after an ordinary Codex launch.
- Native Windows notification-area icon: close to background, double-click to restore, and localized right-click navigation, hide, and exit commands.
- Start with Windows support for packaged and portable deployments.
- Dynamic Store package discovery, managed loopback-port diagnostics, and guarded verified-process controls.
- Settings-based version detection plus a permanent free/open-source and refund notice.
- Chinese File, Edit, View, and Help application menus with theme-aware popup materials.

## Green package

Download `CodexDreamSkin-Windows-x64-v0.3.4.zip`, extract the complete archive, and run:

```text
CodexDreamSkin.exe
```

Keep the EXE beside its included DLL, PRI, runtime, resource, and theme files. This release is self-contained and does not require installing the .NET SDK.

## Safety

- Does not patch Codex binaries, `WindowsApps`, or `app.asar`.
- CDP remains bound to `127.0.0.1`.
- Revalidates package and process identity before guarded takeover or close operations.
- Does not install a hidden PowerShell tray shortcut.
- The notification-area icon runs inside the native manager process.
- This build is currently unsigned; code signing is deferred.
