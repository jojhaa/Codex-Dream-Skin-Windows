# Codex Dream Skin Windows v0.3.5

## 中文版本日志（主要）

`v0.3.5` 对整个 Windows 主题管理器进行了扁平化重构，并将隔离互动预览、真实 Codex 画面回传、主题材质和 CDP 生命周期验证整合为一套完整工作流。

### 主要更新

- 重构为单一 Theme Studio 工作台：顶部品牌操作栏，左侧主题库与编辑工具，中间完整 Codex 预览，右侧属性操作台。
- 隔离预览覆盖 Codex 窗口菜单、侧栏、主页、任务页、输入区和设置页，支持本地场景切换、模拟发送、固定回复和状态重置。
- 新增真实 Codex 画面回传。管理器通过受信任的本机回环 CDP 临时应用主题、捕获完整画面，并按原始比例缩放到预览区。
- 新增“银河夜幕 · 星河玻璃”内置主题，使用星河背景、连续全窗口构图和深色透明玻璃组件。
- 新增左栏连续主背景模式，以及“统一侧栏与工作区透明度”选项。
- 主题格式升级至 schema 11，渲染器升级至 3.10.0。

### 修复与可靠性

- 修复 `CdpSession.SendAsync` 在序列化、发送、取消和断线路径中的 pending 请求残留。
- 新增真实 WebSocket 取消和断线行为测试，验证请求会立即结束且 pending 字典归零。
- 修复完整隔离预览因 MRT 本地化资源冲突导致的启动闪退。
- 修复实时预览未回传完整 Codex 画面的问题。
- 修复背景和 Codex UI 分层缩放导致的比例漂移。
- 修复透明左栏仍残留背景材质、模糊、边框或伪元素的问题。
- 银河主题不再继承人物主题的标题条、丝带、签名或拍立得装饰。
