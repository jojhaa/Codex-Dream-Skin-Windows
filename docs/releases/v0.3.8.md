# Codex Dream Skin Windows v0.3.8

## 中文版本日志（主要）

`v0.3.8` 恢复最新版 Codex Desktop 设置页、拉取请求详情页和 Ctrl+Alt+B 审查侧栏的主题透明度。

### 修复内容

- 适配最新版设置页不再使用旧 `.main-surface` 子节点的结构变化，通过设置搜索框和原生设置控件稳定识别页面。
- 清除设置页新增的 Electron 整页纯色画布，同时保留设置卡片的半透明玻璃材质。
- 清除拉取请求等新版 `app-shell-detail-panel` 详情页的三层纯色基础画布。
- 通过稳定的 `data-app-shell-focus-area="right-panel"` 识别 Ctrl+Alt+B 审查侧栏，清除页面、工具栏、滚动区和粘性操作区底色。
- 样式架构升级至 74，使已运行的 Codex 页面立即替换旧样式。

### 验证

- 真实 Codex 设置页：页面画布完全透明，5 个设置卡片保留玻璃渐变。
- 真实 Codex 拉取请求页：3 个详情基础层完全透明。
- 真实 Ctrl+Alt+B 审查侧栏：6 个基础层完全透明，4 个快捷操作按钮保留轻微交互底色。
- 完整 Windows 自动化测试与 x64 Release 编译通过。
- Portable 与 Lite 发布包均经过全新解压启动验证。

## English Summary

`v0.3.8` restores themed transparency across current Codex Settings, Pull Request details, and the Ctrl+Alt+B review sidebar.

### Highlights

- Recognizes the current Settings structure without depending on the removed `.main-surface` child.
- Clears only page-sized Settings, detail-panel, and review-sidebar foundations.
- Uses the stable `data-app-shell-focus-area="right-panel"` boundary for the current review sidebar.
- Retains glass materials and interaction states for cards, messages, composers, and controls.
- Bumps the style schema to 74 for immediate replacement on active pages.
