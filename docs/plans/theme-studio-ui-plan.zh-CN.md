# Codex 梦幻皮肤主题工作室 UI 重构规划

## 真实渲染预览实施补充（2026-07-25）

中间预览采用双层模式：

- 真实预览：草稿通过正式 `ThemePayloadLoader`、`dream-skin.css` 和 `renderer-inject.js` 注入可信回环端口中的真实 Codex 页面；渲染稳定两个动画帧后，通过 `Page.captureScreenshot` 将当前视口以 PNG 回传到中间区域。该结果与正式应用共用同一渲染链路。
- 离线模拟：Codex 未连接、可信端口不可用、页面切换或截图失败时，立即移除真实帧并恢复可互动的原生 `CodexPreviewFixture`，同时明确标记为模拟结果。

真实帧只保存在内存中，不写入主题目录、历史记录或日志。实时同步继续使用草稿 generation 和取消令牌，旧截图不得覆盖新草稿。真实帧显示期间，首页、任务和设置模拟按钮暂停交互；取消预览或关闭实时同步后恢复正式主题和离线模拟控件。

实时开关、进度和返回状态必须固定在中间预览标题栏，不能藏入主题库或编辑工具的切换面板。任何已选主题都可以获取真实画面；内置主题只限制参数编辑，不限制真实截图回传。

真实截图必须先按捕获视口尺寸建立固定画布，再由单一 `Viewbox Stretch=Uniform` 缩放完整画布；不得让背景、截图或 UI 分别参与布局缩放。状态角标显示源尺寸和当前缩放百分比，窗口变化后重新计算，但不改变源画面宽高比。

## 2. 背景与问题

当前主题页面已具备主题库、图片区域、构图、配色、材质、组件材质、预览、撤销、保存和历史恢复等能力，但主要以纵向页面和多个 `Expander` 组织。随着能力增加，现有结构出现以下问题：

- 主题选择、预览和编辑控件混在同一个长页面中。
- 用户需要滚动较长距离才能找到目标设置。
- 多个编辑领域同时展开，视觉主次不明确。
- 预览面积容易被编辑控件压缩。
- 组件材质、基础材质、颜色和构图之间的职责不够清晰。
- 字体、翻译、悬浮窗口、装饰和真实模块布局尚未形成独立的数据模型。
- 继续向单个 XAML 和代码隐藏文件添加功能会增加状态同步和维护风险。

本次重构需要建立稳定的工作室框架，并为后续能力升级留出明确边界。

## 3. 产品目标

主题工作室应支持以下主流程：

```text
选择主题
  → 选择编辑工具
  → 在右侧修改参数
  → 在中间隔离预览中即时查看
  → 保存草稿
  → 显式应用或同步到真实 Codex
```

用户进入主题页后，应立即理解三个区域的职责：

- 左侧：正在编辑哪个主题，以及使用哪个工具。
- 中间：当前主题在 Codex 界面中的视觉结果。
- 右侧：当前工具可以修改哪些参数。

## 4. 设计原则

### 4.1 视觉命题

采用克制、专业、偏创作工具的 WinUI 工作室风格。中间预览是唯一视觉主角，左右栏使用平静的系统表面、清晰间距和少量分隔，不使用卡片拼贴式仪表盘。

### 4.2 交互原则

- 工具切换不改变中间预览的位置、页面和缩放。
- 参数调整只更新受影响的预览区域。
- 草稿是唯一编辑事实来源，工具之间不保存互相独立的临时副本。
- 保存、应用、实时同步和隔离预览必须是不同状态。
- 不允许主题包提供任意 CSS、脚本、DOM 选择器或系统命令。
- 键盘焦点、选中状态、错误提示和高对比度边界不能被视觉模式删除。

### 4.3 非目标

本次规划不包含：

- 修改 Codex 二进制、`WindowsApps`、`app.asar` 或应用签名。
- 读取或翻译聊天、账号、项目名称等用户数据。
- 从主题包执行脚本。
- 使用截图覆盖伪造可交互 Codex 页面。
- 自动启用开机启动、窗口置顶或自动接管。

## 7. 顶部全局命令栏

顶部只保留会影响整个主题或草稿的操作：

- 当前主题名称。
- 内置、用户、自定义、当前应用等状态。
- 未保存修改提示。
- 撤销和重做。
- 保存。
- 应用到 Codex。
- 实时同步开关及状态。

“更多”菜单收纳低频操作：

- 新建。
- 导入图片。
- 导入主题包。
- 复制主题。
- 导出主题包。
- 删除主题。
- 打开版本记录。

取消预览只在真实 Codex 临时预览运行时出现，不能与隔离预览混为同一状态。

## 8. 左侧主题库

主题库由当前横向列表改为纵向列表，包含：

- 搜索主题。
- 新建主题。
- 导入入口。
- 主题缩略图。
- 主题名称和版本。
- 当前应用标记。
- 内置或用户主题标记。
- 未保存、警告和错误状态。
- 每个主题的上下文菜单。

状态标记约定：

| 状态 | 表现 | 含义 |
| --- | --- | --- |
| 未保存 | 蓝点 | 当前草稿与已保存版本不同 |
| 兼容提示 | 黄点 | 使用旧 schema 默认值或缺少可选素材 |
| 阻断错误 | 红点 | 存在无法保存或应用的问题 |
| 当前应用 | 强调色竖条或对勾 | 真实 Codex 当前使用该主题 |

切换主题前必须复用现有的未保存草稿确认流程。

## 10. 中间 Codex UI 隔离预览

### 10.1 推荐方案

使用本地隔离的 WebView2 预览场景：

- 只加载应用内置的 Codex UI fixture。
- 加载当前草稿生成的主题变量、CSS 和受控 renderer。
- 禁止网络访问。
- 禁止外部导航。
- 不连接真实 Codex CDP。
- 不读取真实聊天、账号、项目和工作区。
- 不执行主题包携带的脚本。

选择 WebView2 的理由：

- 最终主题作用于 Electron DOM 和 CSS，WebView2 比纯 WinUI 模拟更接近真实渲染结果。
- 可以复用渲染器和主题变量，减少管理器预览与真实 Codex 的差异。
- 可以通过固定 fixture 验证主页、任务、设置、菜单和悬浮对象。

### 10.2 预览场景

预览工具栏提供：

- 主页。
- 任务。
- 设置。
- 终端。
- 审查。
- Floating Chat。
- 悬浮预览。
- 侧栏抽屉。
- 菜单。
- 对话框。

预览状态提供：

- 浅色。
- 深色。
- 跟随系统。
- 标准。
- 柔和。
- 无分隔线。
- 适应窗口。
- 100%。
- 放大和缩小。
- 区域辅助线。
- 安全区域。

### 10.3 直接互动预览模型

隔离预览器不是静态截图或只能从外部工具栏切换的样板，而是可直接操作的 Codex 交互模拟器。用户应当像操作真实 Codex 一样，在中间画布内使用鼠标、触摸板和键盘完成界面互动。

所有互动由本地确定性状态机处理：

```text
用户输入
  → 固定交互命令
  → PreviewSessionState
  → 更新 fixture DOM
  → renderer 重新计算受影响区域
  → 显示视觉反馈
```

互动只改变当前 `PreviewSessionState`，不连接业务后端，也不产生系统副作用。

#### 主页互动

- 点击新建任务或建议项，切换到内置任务场景。
- 展开和收起侧栏。
- 选择固定的模拟项目和模拟任务。
- 打开用户菜单、应用菜单和上下文菜单。
- 聚焦输入框并输入临时文字。
- 切换模型下拉框的模拟选项。
- 打开设置页、Floating Chat 和固定预览场景。

#### 任务页互动

- 在输入框输入多行文字。
- 点击模拟发送后，将文字作为临时用户消息插入预览。
- 使用固定延迟显示“生成中”状态，再插入内置模拟回复。
- 展开和收起代码块、Diff、摘要及工具结果。
- 切换终端、文件树和审查面板。
- 打开消息菜单、复制按钮、重试按钮和反馈按钮的视觉状态。
- 滚动消息和代码区域。
- 测试选中、悬停、焦点、按下、禁用、加载和错误状态。

“复制”“重试”“反馈”等动作只显示本地确认状态，不写入系统剪贴板、不发送请求。

#### 设置页互动

- 点击设置左侧导航切换分区。
- 操作开关、下拉框、输入框和单选项。
- 展开高级设置。
- 触发本地信息提示、警告和错误状态。
- 测试长页面滚动和焦点恢复。
- 点击链接时只显示不可导航提示。

设置值只保存在预览会话，不写入管理器设置或真实 Codex 配置。

#### 悬浮对象互动

- 鼠标移入边缘后显示侧栏悬浮抽屉。
- 鼠标离开或按 Escape 后关闭。
- 点击任务条目显示悬浮预览。
- 打开和关闭 Floating Chat。
- 打开菜单、子菜单、对话框、提示和工具提示。
- 使用方向键、Enter、Space、Tab 和 Escape 完成键盘操作。

#### 终端与审查互动

- 终端允许输入临时文本，但不执行命令。
- Enter 只回显内置安全模拟输出。
- 文件树只展开固定的虚构目录。
- 审查页只切换固定 Diff、评论和状态。
- 文件按钮不打开文件系统。
- 路径、分支、用户和项目名称全部使用内置虚构数据。

#### 互动一致性

直接互动预览需要尽量复现真实 Codex 的：

- 悬停、按下、焦点和选中反馈。
- 菜单打开位置和关闭规则。
- 侧栏展开、收起和悬浮抽屉行为。
- 页面切换和滚动。
- 输入框自动增长。
- 对话框焦点约束。
- Escape、Tab、方向键、Enter 和 Space。
- Floating Chat 和悬浮预览生命周期。
- 浅色、深色、高对比度和无分隔线模式。

预览工具栏和画布内导航保持双向同步：用户在画布内打开设置页时，工具栏场景自动显示“设置”；从工具栏切换场景时，画布内导航状态同时更新。

预览工具栏提供“重置互动”动作，用于清空临时消息、输入内容、菜单、对话框、模拟设置和滚动位置，同时保留当前主题草稿、明暗模式、表面模式和缩放。

#### 禁止产生的实际功能

- 不发送网络请求。
- 不连接 OpenAI、GitHub 或其他外部服务。
- 不打开、创建、修改或删除本地文件。
- 不执行终端、Shell、Git 或系统命令。
- 不读取或写入系统剪贴板。
- 不启动、关闭或控制真实 Codex 进程。
- 不读取或修改真实 Codex 设置。
- 不调用真实登录、退出、反馈、更新或扩展功能。
- 不产生操作系统通知。

所有可能产生副作用的控件必须映射为固定的本地模拟命令；没有模拟命令的交互默认拒绝，并显示“隔离预览中不可执行”。

### 10.4 设置页预览

“设置”是中间预览区的一级场景，与主页和任务并列，不能只作为菜单或弹窗的附属状态。

设置页 fixture 采用固定的代表性结构：


fixture 只提供视觉和交互状态，不读取或修改真实 Codex 设置。

设置页应覆盖以下原生界面元素：

- 设置左侧导航及选中状态。
- 页面标题、分组标题和说明文字。
- `ToggleSwitch` 等效开关。
- 下拉选择框。
- 文本输入框。
- 普通按钮、强调按钮和超链接。
- 信息提示、警告和禁用状态。
- 长文本、版本信息和页面底部区域。
- 可滚动的设置内容。

设置页用于重点验证：

- 主题字体、字号、行高和长文案排版。
- 中文、英文和自定义界面翻译。
- 页面、侧栏、组件和输入控件材质。
- 标准、柔和和无分隔线模式。
- 开关、下拉框、按钮、链接、焦点和禁用状态。
- 浅色、深色和高对比度下的层级与可读性。
- 右侧操作台修改后局部热更新，不重置设置页滚动位置。

预览工具栏在设置场景中增加“设置分区”选择：

- 常规。
- 外观。
- 通知。
- 个性化。
- 扩展。
- 关于。

切换设置分区时保持当前主题草稿、明暗模式、无分隔线模式和预览缩放。设置 fixture 中的开关和下拉框可以交互，但状态只存在于隔离预览会话中。

安全要求：

- 不调用真实 Codex 设置 API。
- 不显示真实 API Base URL、API Key、账号或本地路径。
- 不把 fixture 的选择写入 Codex 配置。
- 不允许主题翻译改变设置项的内部命令或标识。
- 外部链接仅显示视觉状态，在隔离预览中不执行导航。

### 10.5 隔离预览与真实 Codex

| 能力 | 隔离预览 | 真实 Codex 同步 |
| --- | --- | --- |
| 默认状态 | 始终可用 | 默认关闭 |
| 数据来源 | 固定本地 fixture | 当前官方 Codex 页面 |
| 网络 | 禁止 | 仅现有 loopback CDP |
| 用户数据 | 不读取 | 不导出、不写入 |
| 互动 | 完整本地模拟，无业务副作用 | 真实 Codex 原生互动 |
| 更新频率 | 草稿即时更新 | 受控节流热重载 |
| 失败影响 | 仅预览区域 | 必须可取消并恢复当前主题 |

## 11. 无分隔线模式

无分隔线模式是“布局与间距”工具中的全局视觉模式。

### 11.1 模式

| 模式 | 行为 |
| --- | --- |
| 标准 | 保留 Codex 原始区域分隔和默认间距 |
| 柔和 | 降低分隔线透明度，保留必要层级 |
| 无分隔线 | 隐藏非功能性描边并合并相邻表面 |

### 11.2 可配置项

- 隐藏侧栏与主界面的竖向分隔线。
- 隐藏标题栏底线。
- 隐藏消息、摘要和工作区卡片描边。
- 隐藏输入区外层非功能性边线。
- 隐藏终端、文件树和审查面板装饰线。
- 将区域间距设为 0、4 或 8px。
- 合并侧栏与主画布材质。
- 合并输入区与页面材质。
- 保留或弱化悬浮对象边框。

### 11.3 不允许隐藏

- 键盘焦点轮廓。
- 选中项状态。
- 输入编辑状态。
- 错误、警告和成功提示。
- 可拖动和调整大小的边界。
- 代码 Diff 语义颜色。
- 高对比度模式要求的边框。

预览中提供“显示区域辅助线”开关，用临时强调色显示被隐藏的逻辑边界。

## 12. 右侧上下文操作台

右栏只显示当前工具，不同时呈现所有设置。

统一结构：

```text
工具名称
一句话说明

主要设置
次要设置
高级设置

恢复当前分组
恢复当前工具
```

交互要求：

- 工具切换时保留各工具最后选中的子对象。
- 右栏独立垂直滚动。
- 中间预览不随右栏滚动。
- 高级设置默认折叠，但不能使用多层嵌套 `Expander`。
- 重置只影响当前分组或当前工具，不能静默重置整个主题。
- 所有修改进入统一撤销和重做栈。

## 13. 响应式策略

| 页面宽度 | 布局 |
| --- | --- |
| ≥ 1440px | 280px 左栏、弹性中栏、400px 右栏 |
| 1180–1439px | 240px 左栏、弹性中栏、340–360px 右栏 |

当前 770×680 最小窗口仍可保留，但窄宽度下不能强行压缩三栏。

- 右侧按钮打开当前工具操作台。

- Escape 关闭抽屉并把焦点返回触发按钮。
- 中间预览保持当前页面、模式和缩放。

| WebView2 fixture 与真实 Codex 漂移 | 预览不准确 | 建立固定 DOM 契约和真实 CDP 对照测试 |
| 互动模拟器行为与真实 Codex 漂移 | 用户误判主题效果 | 对关键菜单、侧栏、输入、设置和悬浮对象建立行为契约测试 |
| 模拟控件意外产生系统副作用 | 安全边界被突破 | 固定本地命令白名单、默认拒绝、禁止网络与主机对象暴露 |
| 工具控件保存独立状态 | 撤销和保存不一致 | 所有操作台只编辑统一草稿 |
| 新 schema 破坏旧主题 | 主题无法加载 | 默认值、迁移和旧版本回归测试 |
| 无分隔线降低可访问性 | 焦点和状态不清晰 | 强制保留功能性边界 |
| 翻译误改用户内容 | 隐私与正确性风险 | 仅允许固定本地化键 |
| 悬浮层拦截点击 | 原生 Codex 失去交互 | 验证 hit-test、焦点和 pointer-events |

## 19. 决策摘要

1. 使用三栏工作室结构，中间预览优先。
2. 左侧采用十二项工具导航，右侧使用上下文操作台。
3. 第一阶段保持行为和 schema 不变。
4. 隔离预览推荐使用禁止联网的本地 WebView2 fixture。
5. 隔离预览与真实 Codex CDP 同步是两个不同状态。
6. 字体、装饰、布局、翻译、悬浮窗口和主题元数据通过受限 schema 实现。
7. 无分隔线模式只能移除装饰性边界，不能移除焦点、状态和高对比度边界。
8. 继续保持 loopback CDP、动态 Store 包发现和不修改 Codex 安装文件的安全边界。
